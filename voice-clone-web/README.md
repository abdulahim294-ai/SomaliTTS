# Somali Voice Studio

Personal-only static interface for the official k2-fsa OmniVoice Hugging Face Space.

- No model weights or inference server are hosted on Vercel.
- Voice samples and text are sent to the Hugging Face Space for processing.
- OmniVoice code is Apache-2.0; pretrained weights are CC-BY-NC. Do not use commercially.
- Free ZeroGPU availability and quotas are controlled by Hugging Face and may change.

Deploy this directory as a static Vercel project with `voice-clone-web` as the root directory.
