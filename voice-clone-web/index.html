حوّل نصوصك الصومالية إلى صوتك

واجهة شخصية بسيطة لتجربة استنساخ الصوت باستخدام OmniVoice. ارفع عينة من صوتك، واكتب النص الصومالي، ثم أنشئ التسجيل وحمّله.

تنبيه مهم: هذه تجربة مجانية تعتمد على حصة GPU المجانية في Hugging Face؛ قد يظهر انتظار أو تتوقف الخدمة عند نفاد الحصة. أوزان OmniVoice مرخّصة CC-BY-NC، لذلك هذا الاستخدام شخصي وغير تجاري فقط. لا تستخدم إلا صوتك أو صوتًا لديك إذن صريح باستنساخه.
١ — عينة صوتك

ارفع تسجيلًا واضحًا مدته 3–10 ثوانٍ، من دون موسيقى أو ضوضاء.

٢ — النص الصومالي

اكتب النص المراد نطقه. اكتب تفريغ العينة المرجعية إن طُلب منك ذلك.

٣ — إنشاء وتنزيل

اختر Somali / so إن ظهر في قائمة اللغات، ثم Generate واحفظ ملف الصوت.

فتح OmniVoice مباشرة ↗إذا لم تظهر الأداة داخل الصفحة، استخدم الزر أعلاه.

الموقع لا يخزّن تسجيلاتك ولا يملك خادم استنساخ خاصًا؛ المعالجة تتم داخل مساحة OmniVoice التابعة لـ Hugging Face وفق توفرها وسياساتها. جودة الصومالية تحتاج تجربة عملية.
